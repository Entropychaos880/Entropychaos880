# Hi, I'm Emmanuel Kiio 👋

I build websites and web apps for businesses in Kenya, from booking and rental sites to full-stack products with APIs and databases. I started out building sites for local businesses, and that still shapes how I work: I focus on things that bring in customers, make bookings easier and are simple for the owner to run.

## What I do

- **Business websites:** fast, mobile-friendly sites for hotels, resorts, rentals, spas and other local businesses
- **Full-stack web apps:** booking systems, dashboards and admin panels backed by real APIs and databases
- **Frontend development:** clean, responsive interfaces that look good on a phone, since that is where most Kenyan customers browse
- **Backend and data:** REST APIs, authentication and database design
